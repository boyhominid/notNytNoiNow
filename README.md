audioConfigFox is a simple scraper for desktop access to NYTimes.com and similar article sites, allowing for access to .MP3 audio

Permissions Used:

    activeTab & scripting: Used to detect audio elements (<audio> tags, <source> elements, and .mp3 links) on the current page only. No data is collected.
    downloads: Enables the "Download" button to save audio files. Downloads are handled by your browser's native download manager. No data is transmitted.

Privacy: This extension does not collect, store, or transmit any user data. All functionality operates locally in your browser.
